# TJ / Terry Robar Executive Personal Brand Site

Premium static website for TJ / Terry Robar, designed as an executive personal brand, founder portfolio, growth strategist profile, and senior sales leadership destination.

## Files

- `index.html` - complete semantic HTML site structure with SEO, Open Graph, and schema metadata
- `styles.css` - responsive dark-mode executive design system
- `script.js` - mobile navigation, scroll reveal, active nav state, and hero canvas visual
- `netlify.toml` - static Netlify configuration

## Deploying to Netlify

This site is dependency-free. Deploy the folder directly to Netlify as a static site.

Build settings:

- Build command: leave blank
- Publish directory: `.`

## Resume PDF

The resume button points to:

```text
/TJ-Robar-Resume.pdf
```

Add the final PDF resume file at the project root with that exact filename before publishing.
